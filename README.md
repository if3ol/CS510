# NarrativeTrack

A narrative-level misinformation tracking system that detects how false narratives evolve across news sources over time.

Instead of labeling individual posts or claims, NarrativeTrack collects articles at scale, groups semantically related claims into narrative clusters, and visualizes how those clusters grow, decay, and give rise to new sub-narratives over time.

Applied to the COVID-19 lab leak narrative (2021–2022), the system discovered five distinct narrative clusters across 658 news domains and detected the emergence of a new sub-narrative (Legal and Censorship Angle) in 2022 that did not exist in 2021.

---

## How It Works

```
GDELT API
   ↓
collect()    — fetch articles in monthly windows (250 per window)
   ↓
clean()      — relevance filter, normalize text, deduplicate
   ↓
embed()      — Sentence-BERT (all-MiniLM-L6-v2, 384-dim vectors)
   ↓
cluster()    — UMAP (384D → 10D) + DBSCAN (narrative grouping)
   ↓
dashboard    — Streamlit: timeline, cluster map, article browser,
               domain analysis, mutation view
```

## Requirements

NarrativeTrack runs entirely in Google Colab. No local installation is required. You need:

- A Google account with Google Drive access
- An ngrok account (free tier) to expose the Streamlit dashboard publicly

All Python dependencies are installed automatically when you run the notebook.

## Quickstart

1. Open `pipeline.ipynb` in Google Colab.

2. Edit the **Config** cell at the top of the notebook:

   ```python
   QUERY      = "covid lab leak"   # GDELT search query
   START_DATE = "20210101"         # Start date (YYYYMMDD)
   END_DATE   = "20230101"         # End date (YYYYMMDD)
   ```

3. Run **Step 1 — Mount Drive** and grant Google Drive access when prompted. All data files will be saved here between sessions.

4. Run **Step 2 — Install Dependencies**. This takes approximately 60 seconds.

5. Run **Step 3 — Collect**. The notebook queries GDELT in monthly windows and saves raw article JSON and CSV files to Drive. Progress and article counts per window are printed as it runs.

6. Run **Step 4 — Clean**. Applies relevance filtering, text normalization, and deduplication. Before and after article counts are printed.

7. Run **Step 5 — Embed**. Generates 384-dimensional Sentence-BERT embeddings for each article title. Prints confirmation of the embedding matrix shape.

8. Run **Step 6 — Cluster**. Runs UMAP dimensionality reduction followed by DBSCAN. Prints the number of clusters found, noise percentage, and representative article titles per cluster.

9. Run **Step 7 — Visualize**. Generates the timeline chart and UMAP scatter plot, saved to Drive.

10. Run **Steps 8–10 — Dashboard**. Launches the Streamlit app and prints a public ngrok URL. Open that URL in any browser to explore the dashboard.

## Configuration

| Parameter    | Default          | Description                              |
|--------------|------------------|------------------------------------------|
| `QUERY`      | `"covid lab leak"` | GDELT full-text search query           |
| `START_DATE` | `"20210101"`     | Collection start date (YYYYMMDD)         |
| `END_DATE`   | `"20230101"`     | Collection end date (YYYYMMDD)           |
| `eps`        | `0.7`            | DBSCAN cluster radius (10D UMAP space)   |
| `min_samples`| `2`              | DBSCAN minimum cluster size              |

To apply NarrativeTrack to a different misinformation narrative, change `QUERY`, `START_DATE`, and `END_DATE` in the Config cell. The rest of the pipeline runs without modification.

## Dashboard Tabs

| Tab | Description |
|-----|-------------|
| Timeline | Stacked area chart showing article volume per cluster by month |
| Cluster Map | 2D UMAP scatter plot of all articles, colored by cluster |
| Article Browser | Filterable table of articles with links to original sources |
| Domain Analysis | Top contributing domains overall and per cluster |
| Mutation View | TF-IDF heatmap of distinctive terms per month, with early vs. late vocabulary shift detection |

## Limitations

- Clustering uses article titles rather than full text, as GDELT does not return article body content.
- Evaluation is qualitative; a quantitative benchmark against labeled ground truth is planned as future work.
